The #1 Rule: Line Up the Decimal Points

Before adding or subtracting decimals, stack them so the decimal points are directly on top of each other.

  3.45
+ 2.70

A Helpful Trick: Adding a Trailing Zero

To add 3.45 + 2.7, first give 2.7 a hundredths digit by writing it as 2.70.

  3.45
+ 2.70

This does NOT change the value — 2.7 and 2.70 are the exact same amount. It just makes the columns line up neatly.

Ask Zoey:

  • "Is 2.7 the same amount of money as 2.70? Why?"

Wait — Isn't This the "Extra Zero" We Avoid?

Two different rules for two different jobs!

Expanded notation: 4,000 + 200 + 00 + 5 — never add extra zeros here.

Column addition/subtraction: 2.7 → 2.70 — adding a trailing zero here is allowed, because it doesn't change the value, it just fills an empty column.

Estimate First!

Before solving, round each decimal to the nearest whole number to check if your final answer makes sense.

3.45 + 2.70 → about 3 + 3 = 6   (actual answer: 6.15 ✓ makes sense!)
