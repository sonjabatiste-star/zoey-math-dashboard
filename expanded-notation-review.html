🔍 Expanded Notation Review

A focused review + extra practice on the #1 mix-up: adding extra zeros

The Mistake to Watch For

When Zoey writes expanded notation, the most common slip-up is adding an extra zero as a "placeholder" — but in expanded notation, we don't need placeholder zeros at all, because each term already shows its own place value.

❌ The Trap

For the number 4,205:

4,205 = 4,000 + 200 + 00 + 5 ❌
4,205 = 4,000 + 200 + 5 ✔️
Why it's wrong: There is no digit in the tens place (it's 0), so we simply skip it — we don't write "00." The "200" already tells us there are 2 hundreds; we never need extra zeros tacked onto a term to "hold a spot."

🌟 The Golden Rule

If a digit is zero, don't write anything for that place at all.

Only add a term for each place that has a digit other than zero.

Step-by-Step Method

  1. Look at the number and find the place value of every digit (thousands, hundreds, tens, ones).
  2. For each digit, multiply it by its place value (example: a 3 in the hundreds place = 3 × 100 = 300).
  3. If a digit is 0, skip it completely — do not write a term for it.
  4. Add the remaining terms together with plus signs.
